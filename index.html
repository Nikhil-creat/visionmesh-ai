Architecture

Twelve services, one mesh.

Vision Engine

ResNet50 backbone, Grad-CAM heatmaps, normalised boxes, 512-d embeddings in pgvector.

Agent Swarm

Triage, vision, RAG, critic, safety and action agents with a self-correcting retrieval loop.

Hybrid RAG + Graph

Dense + full-text search fused by RRF, expanded through a Neo4j component graph.

Voice Copilot

Streaming SSE chat with speech in/out and function calls such as "create GitHub issue".

Security

JWT, Redis rate limits, AES-256-GCM sealing, strict Pydantic v2 validation, security headers.

Observability

OpenTelemetry, Prometheus, Loki and Grafana, with PDF reports and Slack/GitHub/Jira actions.
